# Claude Code Guidance for Garnet

Read `AGENTS.md` first. It is the primary repo guide: project layout,
build/test/format commands, coding rules, git workflow, and RDG/gpu2 module
conventions all live there.

## Skills

Repo-local skill notes live under `agent/skills/` — one folder per skill, each
with a `SKILL.md` whose frontmatter `description` states when it applies.
`agent/skills/README.md` is the authoritative list with one-line summaries.
Before starting a task, check that list and read any SKILL.md that matches the
task at hand.
