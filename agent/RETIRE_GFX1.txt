# Assignment: Retire GFX1 Generation Classes and Modules

---

## Goals

Retire obsolete Gen1 graphics and engine modules from active compilation and archive
them under `src/retired/gfx1/` for reference:
- Old GPU module (`src/core/gpu/`) and old GFX module (`src/core/gfx/`).
- Old monolithic headers (`GNgfx.h`, `GNogl.h`, `GNd3d.h`, `GNengine.h`) and sub-headers
  under `src/inc/garnet/gfx/` (preserving `gfx/image.h` for Gen2), `d3d/`, and `engine/`.
- Gen1 engine module (`src/core/engine/`).
- Old application runner and camera utilities tied to Gen1 GPU (`sampleApp.cpp`, `sampleApp.h`,
  `sampleWorld.h`, `arcball.cpp`, `fpcamera.cpp`, `camera.h`).
- Gen1 CEGUI integration (`src/core/cegui/`).
- Gen1 samples (`bezier`, `dolphin`, `ripple`, `thickline`, `optix`, `portal`, `shadowmap`).
- Gen1 tests (`engine`, `font`, `gpu`, `resdb`, `rt`, `sprite`, `d3d9`, `d3d11`, `cegui`, `ut/gfx`).

Gen2 subsystems (`gpu2`, `rdg2`, `fx2`, `e2`, `fiz`) must compile and pass tests cleanly.

---

## Design

### Reference Archive Directory Structure

Archived code moves into `src/retired/gfx1/`:
- `src/retired/gfx1/src/core/` (gpu, gfx, engine, app, cegui)
- `src/retired/gfx1/src/inc/garnet/` (headers, gfx, d3d, engine)
- `src/retired/gfx1/src/sample/` (bezier, dolphin, ripple, thickline, optix, etc.)
- `src/retired/gfx1/src/test/` (engine, font, gpu, resdb, rt, sprite, d3d9, d3d11, cegui, ut/gfx)

### Gen2 Continuity

- `rapid-image` and `stb_image` implementation in `src/core/gfx/base/image.cpp` is relocated to
  `src/core/base/image.cpp` so that `GN::gfx::img::Image` continues to be built into `GNcore`.
- `src/inc/garnet/gfx/image.h` is preserved at its current path since `GNgpu2.h`, `e2`, and `fx2`
  include it for pixel format and image definitions.
