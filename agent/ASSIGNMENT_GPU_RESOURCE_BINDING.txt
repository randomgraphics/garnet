# Assignment: GPU Resource Binding Policy

Goal: Establish a clear, 3-set GPU resource binding policy for the RDG shader pipeline, and
implement SharedShaderConstants as the first artifact that manages real GPU uniform buffers
for Set 0. Shared C++/GLSL headers ensure layout consistency between CPU and GPU.

---  BINDING LAYOUT POLICY ---

  Set 0 — SharedShaderConstants (global frame, camera, direct lighting)
    Binding 0: GlobalCameraUBO  (layout std140, vertex+fragment)
    Binding 1: DirectLightingUBO (layout std140, vertex+fragment)
    → Managed by SharedShaderConstants; one descriptor set shared by all effects in a frame.

  Set 1 — Per-material data (textures, per-material parameters)
    → Managed by each effect builder (e.g. PbrShading, SkyBox).
    → Content is effect-specific; layout is defined by the effect.

  Set 2 — Per-draw-call data (model matrix, etc.) via dynamic-offset UBO
    → Backend manages a ring-buffer of large UBOs, each draw call uses a dynamic offset.
    → Recycles slots when the GPU signals the fence for the associated frame.
    → NOT YET IMPLEMENTED.

  Push constants: Reserved for small, hot-path immediates (≤128 bytes).
    Currently: still used for model+viewProj while Set 0 is being wired in.
