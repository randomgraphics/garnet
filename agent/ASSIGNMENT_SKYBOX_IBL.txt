# Assignment: Skybox and Environment IBL for draw-mesh

Goal: Extend the draw-mesh sample with (1) a skybox background rendered from a cubemap, and (2) image-based
lighting (IBL) in the PBR shading pass — replacing the current hardcoded `0.03` ambient with physically-based
diffuse irradiance and split-sum specular IBL. When done, `draw-mesh.cpp` renders the DamagedHelmet inside
a skybox, lit by both the existing directional light and an environment map.

--- WORKFLOW / CONVENTIONS ---

- Keep build green after every task. Never proceed to the next task with a compile error.
- Commit after each task (or logical sub-step), then push. Message pattern:
    Assignment Skybox+IBL: <one-liner describing this task> (Task X.Y)
- Break the IBL textures into fallback (1×1) defaults — the code must work even without real assets.
- IBL approach: classic split-sum (UE4 / learnopengl.com):
    diffuse ambient  = irradianceMap.sample(N) * baseColor * (1 - metallic)
    specular ambient = prefilteredEnvMap.sampleLod(R, roughness * MAX_LOD) * (F * envBRDF.x + envBRDF.y)
    where envBRDF    = brdfLut.sample(NdotV, roughness).rg
- Skybox rendering: render a skybox cube/quad behind all geometry. Use depth write = false and set
  z = 1 in clip space (gl_Position = pos.xyww) so it renders at max depth.
- The skybox cubemap (binding 2) is the original env map. The irradianceMap (binding 3) and
  prefilteredEnvMap (binding 4) are pre-convolved. If only the skybox cubemap is provided, other
  maps fall back to 1×1 white.
- Inline small hot-path shader helpers; follow existing code style (see inline-small-functions skill).
- File naming: lowercase-hyphen (see filename-naming-convention skill).
- Minimal code change per step (see minimal-code-change skill).
- If a task is blocked (e.g. cubemap loading not supported), stop and discuss before inventing infra.

Task 3.2 — Implement IBL diffuse in pbr.frag
  Files: src/core/rdg/vk-shaders/pbr.frag

  What:
    Replace `vec3 Lo = baseColor * 0.03; // ambient` with IBL diffuse:
      ```glsl
      vec3 kD_ambient   = (vec3(1.0) - fresnelSchlick(max(dot(N, V), 0.0), F0)) * (1.0 - metallic);
      vec3 irradiance   = texture(u_irradianceMap, N).rgb;
      vec3 Lo           = kD_ambient * baseColor * irradiance;
      ```
    Keep the direct-light loop unchanged.
    The fallback 1×1 black irradiance map means Lo starts at 0 — visually similar to before
    (the existing `0.03` hack disappears; ensure direct light still illuminates the scene).

  Verify:
    - Shader compiles.
    - Sample renders; helmet is not pitch-black (direct light still works).
    - With fallback textures: ambient is black — acceptable.
  Commit: "Assignment Skybox+IBL: add IBL diffuse sampler + replace hardcoded ambient (Task 3.1–3.2)"

Task 3.3 — Implement IBL specular (split-sum) in pbr.frag
  Files: src/core/rdg/vk-shaders/pbr.frag

  What:
    Add split-sum specular after the diffuse ambient term:
      ```glsl
      vec3  R                = reflect(-V, N);
      float NdotV            = max(dot(N, V), 0.0);
      vec3  prefilteredColor = textureLod(u_prefilteredEnvMap, R, roughness * MAX_REFLECTION_LOD).rgb;
      vec2  envBRDF          = texture(u_brdfLut, vec2(NdotV, roughness)).rg;
      vec3  F_env            = fresnelSchlick(NdotV, F0);
      vec3  specular_ambient = prefilteredColor * (F_env * envBRDF.x + envBRDF.y);
      Lo += specular_ambient;
      ```
    Note: `Lo` must be accumulated BEFORE tonemapping/exposure, same as direct-light contributions.

  Verify:
    - Shader compiles.
    - Sample renders; with fallback textures: specular ambient is 0 (prefilteredColor = 0) — acceptable.
  Commit: "Assignment Skybox+IBL: add IBL specular split-sum to pbr.frag (Task 3.3)"
