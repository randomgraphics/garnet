Goal: Extend the draw-mesh sample with (1) a skybox background rendered from a cubemap, and (2) image-based

diffuse irradiance and split-sum specular IBL. When done, `draw-mesh.cpp` renders the DamagedHelmet inside
a skybox, lit by both the existing directional light and an environment map.

- IBL approach: classic split-sum (UE4 / learnopengl.com):
    diffuse ambient  = irradianceMap.sample(N) * baseColor * (1 - metallic)
    specular ambient = prefilteredEnvMap.sampleLod(R, roughness * MAX_LOD) * (F * envBRDF.x + envBRDF.y)
    where envBRDF    = brdfLut.sample(NdotV, roughness).rg
- Skybox rendering: render a skybox cube/quad behind all geometry. Use depth write = false and set
  z = 1 in clip space (gl_Position = pos.xyww) so it renders at max depth.
- The skybox cubemap (binding 2) is the original env map. The irradianceMap (binding 3) and
  prefilteredEnvMap (binding 4) are pre-convolved. If only the skybox cubemap is provided, other
  maps fall back to 1×1 white.

    Interface:
      compile_glsl_shader.py <src1.vert> [<src2.frag> ...] [--out-dir DIR] [--var-name NAME] [-I DIR]...
      - Compiles each GLSL source to SPIR-V and emits a C++ uint32_t header.
      - --var-name: override the C++ array name for a SINGLE source file; for multi-file batches,
        auto-derives the name from the filename:
          solid-triangle.vert → kSolidTriangleVert
          pbr.vert            → kPbrVert
          skybox.frag         → kSkyboxFrag
        (rule: hyphen-words to UpperCamelCase, drop extension, prefix with 'k')
      - Output header name: <stem>-<ext without dot>.spv.h
          solid-triangle.vert → solid-triangle-vert.spv.h
          pbr.frag            → pbr-frag.spv.h
      - --out-dir: where headers are written (default: same dir as first source file).
      - -I: include dirs forwarded to glslc (-I flags, repeatable).
      - Uses same find_glslc() and spv_to_header() logic as the old scripts.
      - Exits non-zero if any glslc invocation fails.

Task 3.3a — Create env/bin/gen-ibl-maps.py: generate irradiance map, prefiltered env map, and BRDF LUT from a cubemap
  Files: env/bin/gen-ibl-maps.py   (NEW)

  What:
    A self-contained Python script that takes a source environment map (equirectangular HDR or
    6-face cubemap folder) and produces all three IBL assets needed by the PBR shader:

    Input:
      gen-ibl-maps.py --input <path-to-hdr-or-cubemap-folder>
                      --out-dir <media/envmap/bad-salzbrunn-walking-hall/>
                      [--face-size 128]          # default cubemap output face resolution
                      [--prefilter-mips 5]       # number of roughness mip levels (default 5)

    Output files written to --out-dir:
      irradiance/       — 6 PNG face images (32×32 default), one per +X/-X/+Y/-Y/+Z/-Z
      prefiltered/      — subdirs mip0/ mip1/ ... mipN/, each with 6 PNG face images
                          mip0 = roughness 0 (mirror), mipN = roughness 1 (fully diffuse)
      brdf-lut.png      — 256×256 2-channel (RG) image: R=scale, G=bias for split-sum

    Algorithm:
      - If input is equirectangular (.hdr/.exr/.png): convert to 6-face cube first using
        standard spherical→cubemap UV mapping.
      - Irradiance map: for each output texel direction N, integrate the hemisphere using
        uniform sampling (Monte Carlo or Riemann sum over spherical coords); output is
        per-face PNG with HDR values clamped to uint8 (use a configurable exposure scale or
        store as float in EXR if imageio supports it).
        Preferred: use 16-bit PNG (uint16) or EXR faces to preserve HDR range.
      - Prefiltered env map: for each mip level k (roughness = k / (mips-1)), importance-sample
        the GGX NDF using the Van der Corput / Halton low-discrepancy sequence; use the same
        sample weights as learnopengl.com's IBL specular convolution. Output per-mip 6-face PNGs.
      - BRDF LUT: for each (NdotV, roughness) texel, integrate the split-sum BRDF using
        the same importance-sampling scheme; output a 256×256 2-channel image (R=G in grayscale
        for now; or use a 2-channel format if imageio allows). Store as 16-bit PNG.
      - Dependencies: numpy, imageio (both available in garnet's Python env or installable via pip).
        No C++ required — pure Python.

    NOTE: The script output format (face count, naming, bit-depth) must match what
    Task 3.4 / draw-mesh.cpp loads via Texture::loadCubeFaces(). Keep both in sync.

  Verify:
    - Run manually on the downloaded HDR from media/envmap/bad-salzbrunn-walking-hall/README.md.
    - Visually inspect irradiance faces (should be low-frequency, blurry env colors).
    - Inspect brdf-lut.png (should resemble the well-known split-sum LUT image from learnopengl.com).
    - Script exits 0 with no exceptions.
  Commit: "Assignment Skybox+IBL: add env/bin/gen-ibl-maps.py for IBL asset generation (Task 3.3a)"
