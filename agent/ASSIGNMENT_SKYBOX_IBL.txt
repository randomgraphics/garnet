# Assignment: Skybox and Environment IBL for draw-mesh

---

## Goals

Extend the `draw-mesh` sample with (1) a skybox background rendered from an environment cubemap
and (2) image-based lighting (IBL) in the PBR shading pass — replacing the current hardcoded
`0.03` ambient term with physically-based diffuse irradiance and split-sum specular IBL.

When done, `draw-mesh.cpp` renders the DamagedHelmet inside a visible skybox, lit by both the
existing directional light and the environment map. The skybox and PBR IBL share the same four
scene-level textures (skyboxCubemap, irradianceMap, prefilteredEnvMap, brdfLut) stored in
`SharedShaderConstants` and bound as Set 0 bindings 2–5.

Branch: `feature/rdg/skybox-ibl` (off `feature/rdg/main`; do NOT pollute main).

---

## Design

### GPU descriptor layout (Set 0 after this assignment)

| Set | Binding | Type | Content |
|-----|---------|------|---------|
| 0 | 0 | UBO | GlobalCameraUBO (view, proj, camera pos, RT size, frame) |
| 0 | 1 | UBO | DirectLightingUBO (up to 16 direct lights) |
| 0 | 2 | samplerCube | skyboxCubemap — rendered as background; also the raw env map |
| 0 | 3 | samplerCube | irradianceMap — preconvolved Lambertian diffuse IBL |
| 0 | 4 | samplerCube | prefilteredEnvMap — mip-mapped specular IBL (roughness → mip) |
| 0 | 5 | sampler2D | brdfLut — split-sum BRDF LUT (NdotV × roughness → scale, bias) |
| 1 | 0–2 | sampler2D | PBR material maps (base color, ARM, normal) |
| push | — | 64 B | model matrix (mat4) |

Bindings declared in the GLSL shader but not present in the PSO layout are silently ignored by
rapid-vulkan's Drawable. SSC can safely supply all 6 bindings; each effect only uses what it
declares in its shader.

### Cubemap support findings (Task 1.3–1.5)

`Texture::Descriptor` already has a `faces` field (1 = 2D, 6 = cubemap). The Vulkan backend
was calling `set2D(w,h,faces)` unconditionally, which cleared `eCubeCompatible` and produced a
2D array view even for `faces=6`. Fix: call `setCube(w)` when `faces==6 && depth==1`.
`getTextureImageView` was hardcoding `e2D`; fix: omit `setType` for cubemaps so rapid-vulkan
auto-detects `eCube`. `upload1x1Mip` was uploading only face 0; fix: loop over all faces.

### IBL approach (Phase 4)

Classic split-sum (UE4 / learnopengl.com):
- Diffuse: `ambient_d = kD * baseColor * texture(u_irradianceMap, N).rgb`
- Specular: `ambient_s = textureLod(u_prefilteredEnvMap, R, roughness * MAX_LOD).rgb * (F*brdf.x + brdf.y)`
- BRDF LUT generated by `env/bin/gen-ibl-maps.py` (pure-Python, numpy + imageio).

### Skybox rendering (Phase 3)

Full-screen triangle (3 verts, no VBO); vertex shader reconstructs world-space ray direction from
`gl_VertexIndex` using the inverse-view-rotation (no translation) from the camera UBO. Fragment
samples `samplerCube u_skyboxCubemap`. Depth write = false; `gl_Position.z = gl_Position.w`
so skybox always renders at max depth (behind all geometry).

### Shader compile infrastructure (Phase 2)

Two per-shader Python scripts (`compile_pbr_shaders.py`, `compile_shaders.py`) are replaced by a
single `env/bin/compile_glsl_shader.py` that compiles any GLSL source to a SPIR-V uint32_t header.
Variable name auto-derived: `solid-triangle.vert` → `kSolidTriangleVert`, header `solid-triangle-vert.spv.h`.

--- WORKFLOW / CONVENTIONS ---

- Keep build green after every task. Never proceed with a compile error.
- Commit after each task, then push immediately. Message format:
    "Assignment Skybox+IBL: <one-liner> (Phase N.M)"
- IBL fallback rule: all env textures default to 1×1 black cubemap (bindings 2-4) or 1×1 white
  2D (binding 5). The sample must run without crash even if no env assets are loaded.
- Skybox depth: depth write = false, gl_Position.z = gl_Position.w (clips to z=1.0 max).
- rapid-vulkan Drawable silently skips bindings not declared in the shader's SPIR-V. It is safe to
  always supply all 6 Set 0 bindings from SSC regardless of which shader is active.
- Shader naming: skybox.vert, skybox.frag (lowercase-hyphen file naming convention).
- Minimal code change per step. If a change grows large, split it.
- Phase 2.1x tasks were triggered by the cubemap investigation and are already done in Phase 1.
