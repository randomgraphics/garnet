# Assignment: FX2 Bindless Cel Shading Kernel, Material, and Sample

---

## Goals

Implement stylized non-photorealistic (NPR) anime cel shading within the modern `GN::fx2::bindless` architecture.
The effect consumes `gpu2::bindless::DescriptorHeap`, `bindless::Raster`, and `bindless::SharedShaderConstants`, providing:
1. Multi-band stepped cartoon diffuse shading (Half-Lambert wrap, 2-band smoothstep quantized shadow ramps with cool/warm tints).
2. Stepped Blinn-Phong cartoon specular highlights with sharp thresholds.
3. Stylized Fresnel rim lighting with anime edge glow and directional bias.
4. Inverted-hull silhouette outline pass with clip-space aspect-ratio-corrected normal extrusion.
5. Typed public `CelKernel` and `CelMaterial` interfaces in `src/inc/garnet/fx2/bindless/cel.h` and monolithic include in `GNfx2.h`.
6. Unit tests in `src/core/fx2/test/bindless-cel-test.cpp` verifying material creation, parameter validation, and offscreen pixel rendering.
7. Standalone sample application `GNsample-fx2-cel-shading` in `src/sample/fx2/simple-cel-shading.cpp`.

## Design

### 1. Material Data and Shaders
`CelMaterialData` is packed in std430 layout in the descriptor heap material buffer:
- `baseColor`: vec4
- `emissive`: vec4
- `shadowParams`: vec4 (x = shadowThreshold, y = shadowFeather, z = deepShadowThreshold, w = deepShadowFeather)
- `shadowTint`: vec4 (rgb = shadowTint, a = unused)
- `deepShadowTint`: vec4 (rgb = deepShadowTint, a = unused)
- `specularParams`: vec4 (x = specularThreshold, y = specularShininess, z = specularIntensity, w = unused)
- `rimParams`: vec4 (x = rimThreshold, y = rimFeather, z = rimIntensity, w = unused)
- `rimTint`: vec4 (rgb = rimTint, a = unused)
- `outlineParams`: vec4 (x = outlineWidth, yzw = unused)
- `outlineColor`: vec4 (rgba = outlineColor)
- `textureIndices`: uvec4 (x = colorIndex, y = normalIndex, z = samplerIndex, w = flags)

Total size = 176 bytes (aligned to 16 bytes).

Shaders:
- `bindless-cel-material.h`: std430 CelMaterialData buffer definition.
- `bindless-cel-vertex.h`: vertex shader shared code for textured and untextured variants.
- `bindless-cel.vert` & `bindless-cel-texture.vert`: surface vertex shaders.
- `bindless-cel.frag`: multi-band diffuse, stepped Blinn-Phong, stylized rim light, and Reinhard tone mapping.
- `bindless-cel-outline-vertex.h`: inverted-hull silhouette vertex extrusion in clip space.
- `bindless-cel-outline.vert` & `bindless-cel-outline-texture.vert`: outline vertex shaders.
- `bindless-cel-outline.frag`: outline color output.

### 2. C++ Interfaces
- `src/inc/garnet/fx2/bindless/cel.h`:
  - `CelMaterial::Parameters`: color, emissive, shadow/specular/rim/outline parameters, maps, and sampler.
  - `CelMaterial::DrawParameters`: geometry, SSC state, raster, world transform, `renderOutline` flag.
  - `CelKernel::defaultMaterialParameters()`
  - `CelKernel::createMaterial(CnC &, const Parameters &)`
  - `CelKernel::create(DescriptorHeap &, CnC &)`
- `CelMaterialImpl::record(const DrawParameters &)` records the surface draw, and if `renderOutline` is true and `outlineWidth > 0`, records the inverted-hull outline draw with `CULL_FRONT` and `LESS_EQUAL` depth.

### 3. Sample and Tests
- `src/core/fx2/test/bindless-cel-test.cpp`: tests creation, fallback defaults, invalid parameters, and offscreen rendering of cel diffuse steps and outline.
- `src/sample/fx2/simple-cel-shading.cpp`: interactive demo orbiting a sample mesh with sun lighting, toon shadows, and silhouette outlines.
