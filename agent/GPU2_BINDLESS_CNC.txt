# Assignment: GPU2 Bindless CnC (Copy & Compute) Subsystem

---

## Goals

Extend the `GN::gpu2::bindless` subsystem to include high-throughput non-graphics operations
(`bindless::CnC`), mirroring the performance and design advantages of `bindless::Raster`:
eliminating per-dispatch descriptor set compilation, per-dispatch table scanning, and per-dispatch
heap allocations.

1. **Bindless CnC Recorder (`bindless::CnC`)**:
   Implement direct Vulkan command recording with lean `ComputeParameters` (no `GpuResourceTable`),
   plain POD `CreateParameters` with conflict validation against `heapSetIndex`, internal
   compute `VkPipelineLayout` caching, and full support for asynchronous transfer and copy
   operations (`recordCopyBufferToBuffer`, `recordUploadBuffer`, `recordDownloadBuffer`,
   `recordCopyBufferToImage`, `recordDownloadImage`).
2. **Native Compute PSO Caching (`VkBindlessComputePsoCache`)**:
   Provide a lightweight, thread-safe compute pipeline cache keyed on `(VkPipelineLayout, shaderModule)`
   in `gpu2`, directly calling `vkCreateComputePipelines` and bypassing `rv::Drawable` / `rv::ComputePipeline`.
3. **Bindless CnC Payload & Automated Synchronization (`VkBindlessCncPayload`)**:
   Bind the global descriptor heap once at pass start, push constants directly into `vkCmdPushConstants`,
   dispatch directly via `vkCmdDispatch`, handle pipeline barriers for memory coherency between
   dispatches and transfers, and fulfill download futures on completion.
4. **Verification & Demonstration**:
   Validate with comprehensive unit tests in `GNtest-internal`, including bindless texture/buffer
   access, push constant dispatching, transfer operations, and a 10,000+ dispatch stress test.

---

## Design

### 1. `bindless::CnC` Interface
- Public interface declared in `<garnet/gpu2/bindless.h>` under `namespace GN::gpu2::bindless`.
- Plain POD `CreateParameters`: `gpu`, `heap`, `heapSetIndex`, `passResources`, `maxImmediateSize`.
- Lean `ComputeParameters`: `cs`, `x`, `y`, `z`, and `ArrayView<const uint8_t> immediates` (push constants).
  Shaders access bindless resources through `DescriptorHeap` and pass-wide resources through `passResources`.
- Unified copy/transfer operations matching `GpuCnC` contracts:
  - `recordCopyBufferToBuffer`
  - `recordUploadBuffer`
  - `recordDownloadBuffer` (returns `std::future<AutoRef<const Blob>>`)
  - `recordCopyBufferToImage`
  - `recordDownloadImage` (returns `std::future<TextureContent>`)
- `retainCleanup()` and `retainResource()` for parameter buffer and staging lifetime management.

### 2. Pipeline Layout & Compute PSO Caching
- Generalize `VkBindlessPipelineLayoutCache` to support compute stage flags (`vk::ShaderStageFlagBits::eCompute`).
- Add `VkBindlessComputePsoCache` to `GpuContextVulkan2` for fast get-or-create of native `vk::Pipeline` compute handles.

### 3. Direct Vulkan Recording & Synchronization
- Commands are recorded into an ordered list of operations: compute dispatches and memory transfers.
- Payload binds `mHeap` once at `heapSetIndex` for `vk::PipelineBindPoint::eCompute`.
- Direct `vkCmdPushConstants` and `vkCmdDispatch`.
- Execution and memory barriers between write/read hazards (e.g. compute writes visible to subsequent dispatches or transfers).
- Futures for downloads resolved on `onGpuComplete()`.
