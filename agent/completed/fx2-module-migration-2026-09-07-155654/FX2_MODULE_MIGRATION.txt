# Assignment: FX2 Module Migration

---

## Goals

Create the independent FX2 effects module above gpu2 and move ownership of shared shader constants, PBR rendering, their shaders, tests, and direct sample out of RDG2 without duplicate APIs or implementations.

---

## Design

### Module boundary

`GNfx2.h` is the only public include for `GN::fx2`. FX2 includes `GNgpu2.h` and does not include or reference RDG2. RDG2 may reference FX2 only where graph-specific adapter declarations need effect types.

### Ownership

FX2 owns SharedShaderConstants, PbrShading, the PBR/skybox shader sources and generated-header integration, FX2-local tests, and the direct PBR sample. RDG2 retains graph primitives and graph-focused consumers only.

--- WORKFLOW / CONVENTIONS ---

- Make all edits only in the FX2 worktree.
- Public clients include only `GNfx2.h` for FX2 APIs.
- FX2 depends on gpu2 only; RDG2 dependencies are forbidden in FX2 sources and headers.
- Preserve graph-specific adapters in RDG2 and avoid compatibility aliases that duplicate ownership.
