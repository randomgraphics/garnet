# Assignment: FX2 Genshin-Style Cel (NPR) Shading

---

## Goals

Implement a stylized non-photorealistic (NPR) cel-shading effect in the `fx2` module (`GN::fx2`), capturing the iconic Genshin Impact / modern anime aesthetic. The effect integrates seamlessly with existing normalized `ModelAsset` geometry and `SharedShaderConstants` environment lighting, providing:

1. Multi-band stepped cartoon diffuse shading (Half-Lambert wrap, 2-band/3-band quantized shadow ramps with stylized cool/warm shadow tints).
2. Stepped Blinn-Phong cartoon specular highlights with sharp thresholds.
3. Stylized Fresnel rim lighting with anime edge glow and directional bias.
4. Inverted-hull silhouette outline rendering pass with clip-space aspect-ratio-corrected normal extrusion and alpha-cutout clipping.
5. Runtime-tunable shading configuration (`CelModelShading::Config`).
6. A standalone sample application (`GNsample-fx2-cel-shading`) demonstrating the anime shading look.

---

## Design

### 1. Cel Shading Pipeline & Parameter UBO

`CelModelShading` consumes existing `ModelAsset` instances without altering their geometry or CPU representations. Shading parameters are encapsulated in a 128-byte `std140`-aligned UBO (`cel-shading-ubo.h`) bound to descriptor Set 1, Binding 6:
- `shadowParams`: `(shadowThreshold, shadowFeather, deepShadowThreshold, deepShadowFeather)`
- `shadowTint`: `(rgb = cool/warm shadow color, a = unused)`
- `deepShadowTint`: `(rgb = crease/deep shadow tint, a = unused)`
- `specularParams`: `(specularThreshold, specularShininess, specularIntensity, unused)`
- `rimParams`: `(rimThreshold, rimFeather, rimIntensity, unused)`
- `rimTint`: `(rgb = rim highlight color, a = unused)`
- `outlineParams`: `(outlineWidth, unused...)`
- `outlineColor`: `(rgba = outline ink color)`

### 2. Shaders

- `cel-model.vert` & `cel-model.frag`:
  - Computes Half-Lambert `0.5 * dot(N, L) + 0.5`.
  - Applies smoothstep quantizing across primary and deep shadow thresholds, blending between `baseColor`, `shadowTint`, and `deepShadowTint`.
  - Blends soft ambient from `SceneUBO` / irradiance to prevent unnatural black voids.
  - Adds sharp anime specular highlight using step-filtered Blinn-Phong lobe.
  - Adds Fresnel rim light modulated by light visibility.
- `cel-outline.vert` & `cel-outline.frag`:
  - Extrudes vertices along view-projected normal in clip space: `offset = normalize(clipNormal.xy) * outlineWidth * clipPos.w`, adjusted by `aspectRatio`.
  - Uses `RasterState::CULL_FRONT` to cull front faces and only render the extruded back-facing silhouette shell.
  - Fragment shader discards pixels failing `alphaCutoff` to prevent blocky outlines around alpha-cutout geometry (e.g. hair cards, ribbons).

### 3. Public API

Exposed in `src/inc/garnet/fx2/cel-shading.h` and included in monolithic `GNfx2.h`:
- `CelModelShading::Config`: value struct of tuning parameters.
- `CelModelShading::Asset`: opaque pure virtual interface extending `RCRT64`.
- `CelModelShading::create(gpu, config)`: factory returning `AutoRef<Asset>`.
- `CelModelShading::getDrawParams(...)`: builds surface draw parameters.
- `CelModelShading::getOutlineDrawParams(...)`: builds inverted-hull outline draw parameters.
