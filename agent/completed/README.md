# Completed Tasks

Each completed task is archived as a directory:
`agent/completed/<task>-<yyyy-MM-dd-HHmmss>/`. The timestamp is UTC. The folder
contains the final `TASK.md` and task-specific evidence or notes, with internal
structure preserved. Legacy imports retain their original record filenames and
may not contain a `TASK.md`.

The archive is historical reference material. Do not rewrite task records to
match current conventions, and do not delete them as routine cleanup. Update
live links when paths move.

Legacy documents imported from the old flat archive may not record their true
completion time. When possible, their directory timestamp is the UTC timestamp
of the Git commit that last archived or updated that record. For these imports,
the timestamp identifies the archive record date and may differ from the actual
implementation completion date.
