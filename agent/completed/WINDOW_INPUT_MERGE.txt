## Goals

Replace the standalone input singleton with per-window keyboard and mouse state,
events, and queries on `GN::win::Window`. Retain only GLFW and native Win32 as
real window backends, migrate all clients, remove the old input module, and add
internal Catch2 tests for backend-independent input behavior.

---

## Design

### Public API

Move key codes, key status/events, axes, conversion helpers, input signals,
queued key-event access, key/axis state, and mouse-position access into
`GNwin.h` and namespace `GN::win`. A window owns its input state; pumping window
events updates the state and emits signals.

### Backends

GLFW uses window-local callbacks. Native Win32 translates messages in the
window procedure and attached-window hook. Qt and X11 window implementations,
plus all standalone native/DirectInput/XInput implementations, are removed.

### Verification

Backend-independent event/state semantics are exercised through a test window
in the internal Catch2 executable. Linux builds exercise the GLFW production
backend at compile/link time.
