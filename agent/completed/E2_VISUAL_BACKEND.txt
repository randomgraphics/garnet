# Assignment: E2 Visual Backend on FX2 and RDG2

---

## Goals

Refactor the engine2 visual moment and visual domain path around the new FX2 and RDG2 boundaries. A world captures a fixed, self-contained visual moment tree. The visual domain consumes that immutable snapshot, chooses the concrete frame workload, compiles it as an RDG2 closed plan, and executes it.

Keep FX2 limited to atomic, graph-agnostic rendering features over gpu2. Keep RDG2 limited to the generic closed render-graph framework. All adaptation between engine snapshot data, FX2 effects, and RDG2 quests belongs to the E2 visual backend.

---

## Design

### Ownership boundaries

World and visual facets own live simulation state. `VisualMoment` owns only fixed render-facing state captured under the world's synchronization boundary. FX2 accepts render-space values and produces resource tables, draw parameters, and sealed GPU payloads without knowing about graphs or worlds. RDG2 orders declared artifact work, gathers payloads, submits them, and presents. `VisualDomain` is the composition root for all three.

### Frame flow

For each submitted visual moment, E2 seals the snapshot in an imported RDG2 artifact and builds a concrete closed frame plan:

`frame begin (acquire) -> visual render (moment + backbuffer) -> frame end (present)`

The render quest reads only the sealed moment relic, converts exact camera-relative world coordinates to float meters, snapshots FX2 shared shader constants, records draw work, republishes the rendered backbuffer relic, and emits all FX2 and raster payloads. RDG2 owns submit and present ordering.

--- WORKFLOW / CONVENTIONS ---

- FX2 must not include or reference E2 or RDG2.
- RDG2 stays generic and must not include or reference E2.
- E2 may include the monolithic `GNfx2.h` and `GNrdg2.h` headers in implementation files.
- A closed plan observes only fixed moment/relic data and declared artifacts; it never reaches back into live world state.
- Exact world-coordinate rebasing happens in E2 before values cross into FX2 render space.
- Per-frame GPU submission and presentation go through RDG2 execution.
- Preserve Vulkan teardown ordering and avoid render-critical blocking upload APIs.
