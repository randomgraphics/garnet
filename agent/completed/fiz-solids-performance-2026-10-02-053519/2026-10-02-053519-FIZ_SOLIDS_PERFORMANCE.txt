# Assignment: Optimize performance of fiz solid demo
---
## Goals
Eliminate CPU rendering overhead in the fiz solid demo, maximizing frame rate and achieving > 400 FPS (sub-2.5 ms per frame) for 1024 colliding rigid bodies.
---
## Design
1. Extend FX2 lit raster kernels (`PbrKernel`, `LambertianKernel`, `CelKernel`) to accept optional batch transforms `ArrayView<const glm::mat4> transforms = {}`.
   - When multiple instance transforms are supplied, allocate and upload uniform parameters once and construct the resource table once.
   - Emit draws with per-instance world matrices and transpose inverse normal matrices via immediates push constants.
   - Consecutive draws with matching configuration (geometry, state, resource table, shaders) hit the GPU raster payload fast-path cache, avoiding pipeline rebinds, descriptor set allocations/writes, and buffer rebinds.
2. Update `src/sample/fiz/solids.cpp` to group simulated entities by `ModelKind`, batching per-model world transforms into retained vectors.
   - Optimize transform composition: set translation directly into matrix column 3 instead of performing full 4x4 matrix multiplications.
   - Record batches via `pbr->record` with the batched transforms.
3. Verify headless test mode, test suite, and interactive performance telemetry.
