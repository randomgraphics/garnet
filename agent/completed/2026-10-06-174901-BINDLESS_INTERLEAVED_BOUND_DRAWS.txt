# Assignment: Bindless Raster Interleaved Bind-Based Draws and ImGui Integration

---

## Goals

1. Add a dedicated method `recordBindBasedDraw(const DrawParameters & params, const GpuResourceTable & drawResources)` to `GN::gpu2::bindless::Raster`.
2. Enforce the descriptor heap set conflict invariant: `drawResources` must not define bindings in the same set as `heapSetIndex`. If a conflict occurs, the draw fails.
3. Preserve zero descriptor compilation and zero hazard scanning overhead for pure bindless passes and pure bindless draws.
4. Support dynamic pipeline layouts and descriptor set binding per draw for bind-based draws within the same render pass, keeping bound resources alive for the duration of the pass.
5. Make `fx2::ImGuiBackend` descriptor set index configurable via `CreateParameters::resourceSetIndex` (default 0), patching the fragment SPIR-V binary when `resourceSetIndex != 0`.
6. Add an overload `ImGuiBackend::record(gpu2::bindless::Raster & raster, AutoRef<gpu2::GpuPayload> & uploads)` to record UI draws directly into a bindless raster pass.
7. Migrate `mesh-viewer` to render its ImGui UI overlay within the same bindless render pass, eliminating the secondary pass and backbuffer reload.
8. Add comprehensive unit tests in `src/core/gpu2/test/bindless-raster-test.cpp` and `src/core/fx2/test/imgui-backend-test.cpp`.

---

## Design

### 1. Dedicated Method on `bindless::Raster`
In `src/inc/garnet/gpu2/bindless.h`:
```cpp
virtual void recordBindBasedDraw(const DrawParameters & params, const GpuResourceTable & drawResources) = 0;
```
- Validates `drawResources`: if `heapSetIndex < drawResources.size() && !drawResources[heapSetIndex].empty()`, logs an error and returns without recording.
- If `drawResources` is empty, delegates to pure bindless recording.
- Non-empty `drawResources` are deduplicated into `mBoundResourceTables`.
- Each recorded draw in `mStorage->draws` stores `boundResourceIndex` (`~0u` for pure bindless draws).

### 2. Descriptor Allocation and Pipeline Layout Caching
- At `seal()` time, if `mBoundResourceTables` is non-empty:
  - Allocates a pass-level `vk::DescriptorPool` for all bound draw tables.
  - For each unique table:
    - Merges with `mPassResources` into `combinedTable`.
    - Retrieves or creates `drawLayout` from `VkBindlessPipelineLayoutCache`.
    - Allocates and updates `vk::DescriptorSet`s for sets in `drawResources` (`s != heapSetIndex`).
    - Stores entry `{ drawLayout, descriptorSets }`.
- In `VkBindlessPayload`:
  - Registers all bound resource tables into `ctx.batchTracker` for automatic barrier generation.
  - When submitting draws:
    - Tracks `activePipelineLayout` and `activeBoundResourceIndex`.
    - Binds the draw's pipeline layout and descriptor sets only when changed.
    - Subsequent pure bindless draws revert to `mPipelineLayout` and pass sets.

### 3. Configurable `ImGuiBackend` Set Index and Bindless Recording
- `fx2::ImGuiBackend::CreateParameters` adds `uint32_t resourceSetIndex = 0;`.
- When `resourceSetIndex != 0`, SPIR-V words for `kImguiFragSpv` are patched by replacing `OpDecorate %uiTexture DescriptorSet 0` with `resourceSetIndex`.
- `ImGuiBackend::record(gpu2::bindless::Raster & raster, AutoRef<gpu2::GpuPayload> & uploads)`:
  - Prepares vertex/index buffers and upload work via CnC.
  - For each draw command: creates `drawResources` with `drawResources[resourceSetIndex][0][0] = texture`, and calls `raster.recordBindBasedDraw(draw, drawResources)`.
