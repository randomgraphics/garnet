# Assignment: Enable Vulkan memory suballocation and measure solids performance
---
## Goals
Keep independent material and staging buffers while replacing per-buffer device
memory allocations with VMA suballocations. Measure the allocator change alone.
---
## Design
Complete rapid-vulkan's existing optional VMA initialization and mapping paths.
Pass loaded Vulkan entry points to VMA and cap the device API version at the selected VMA header's supported version.
Preserve dedicated-allocation fallback and all GPU resource lifetimes. Do not add
buffer pools, persistent staging maps, or material deduplication in this task.
