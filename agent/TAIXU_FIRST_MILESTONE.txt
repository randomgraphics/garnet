# Assignment: 太虚首个里程碑——单人创作闭环原型
---
## Goals

将太虚愿景转化为第一个可体验的产品验证：单个用户进入一个小型 3D 世界并进行探索，通过脚本浏览世界、提交一项简单修改，看到修改应用到世界中，然后继续探索。原型要验证太虚世界可由程序理解和操作的基础，不试图一开始就构建通用编辑器、完整 AI 内容生产管线或可公开发布的平台。

当这个闭环能在可运行的 Garnet 原型中端到端工作，且世界修改以经过验证的语义数据表示、再由渲染器消费时，里程碑即告完成。实现应保持精简，便于根据产品验证结果调整。

## Design

### 里程碑

**M1——单人创作闭环原型**

在一个小型私有 3D 世界中演示 `探索 → 脚本查询世界 → 脚本提交修改 → 继续探索`。通过 Python binding 暴露一套最小但一致的世界浏览与修改 API。脚本至少能读取世界中的语义实体及其空间信息，并提交一项范围明确的修改，例如在指定位置添加一间简单木屋。资产生成、自然语言模型接入、照片级画质、多人功能、公开发布、声誉系统和移动端性能指标都不属于 M1 的验收要求。

实现必须保留愿景中的架构约束：AI 编辑语义世界数据，而非直接操作渲染器对象；渲染资源由语义数据派生；修改在显示前先经过验证；平台与渲染方案不能从结构上阻碍未来支持移动端和世界流式加载。这些约束用于指导接口与数据所有权，但 M1 不交付移动端功能对等、大世界流式加载、渐进式 LOD 或生产级安全治理系统。

### 检查点

1. **C1——可运行的世界外壳。** Garnet 应用启动后直接进入一个小型 3D 世界，支持舒适的第一人称漫游，并通过简单的场景内交互选择或指示修改位置。不引入专业编辑器工作流。
2. **C2——语义编辑基础。** 小型世界模型能够独立于 GPU/渲染对象表示具名语义实体及其空间数据。一条明确、确定性的编辑命令可以添加示例实体、验证修改、更新可见世界，并在保存后支持重新载入。
3. **C3——Python 世界浏览与修改 API。** 提供一套稳定、最小化的世界操作 API 及 Python binding。脚本能够查询世界实体和空间信息，并调用与 C2 相同的验证、编辑路径提交修改；修改更新可见世界。无效修改应有明确错误反馈，且不得留下部分状态。用一段可运行脚本演示“查询当前世界、在指定位置添加木屋、确认新实体出现在查询结果和 3D 视图中”。

每个检查点完成时都应有可运行的演示，并简要记录已验证内容、暂缓内容，以及影响未来移动端或流式加载支持的架构决策。C3 的 Python API 应作为未来 AI 操作世界的受控入口候选；M1 不负责接入 AI 模型。

### 明确暂缓的内容

- 多人世界、账户、社交图谱、发布与发现机制、创作者声誉。
- 自然语言模型接入、通用自然语言世界编辑，以及任意几何体或资产生成。
- 生产级模型选择与推理、提示词安全策略，以及完善的恢复与撤销历史。
- 移动端正式交付与性能认证、网页交付、大世界流式加载、渐进式 LOD 实现。
- 完整物理、动画、高级光照和大规模内容库。
