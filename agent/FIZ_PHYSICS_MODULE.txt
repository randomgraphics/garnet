## Goals

This assignment establishes Garnet's physics and continuous media simulation
architecture. The work introduces two complementary layers:

1. `GNfiz` (`GN::fiz`): a standalone, low-level physics module under `src/core/fiz/`
   and `src/inc/garnet/GNfiz.h` occupying the same architectural tier as `gpu2`
   and `fx2`. It delivers atomic, reusable, world-agnostic simulation routines:
   - Rigid-body mechanics (`Solid`, `Hull`, `Temper`) backed by Jolt Physics.
   - Soft and bouncy volumetric bodies (`Gel`) via GPU XPBD tetrahedral volume constraints.
   - Flexible 2D/1D bodies (`Weft` cloth and `Strand` hair) via GPU XPBD compute pipelines.
   - Gaseous media (`Plume` smoke and `Blaze` fire) via 3D Eulerian Navier-Stokes grids.
   - Liquids (`Current` SPH/FLIP particles and `Tide` FFT ocean wave spectra).
2. `PhysicalDomain`, `PhysicalTableau` & `PhysicalFacet`: high-level simulation integration in
   `engine2` (`GN::e2`) under `src/inc/garnet/e2/physical.h`.
   - Independent simulation timeline, decoupled from main game loop and rendering.
   - Canonical `UnitOfTime` (integer nanoseconds) with true mathematical $T$-symmetry
     (negative integer stepping $-\Delta t$ with bit-identical determinism and zero history cache).
   - Support for time scaling (`timeScale`), slow motion, pausing, and single-stepping.
   - Alpha-state interpolation for jitter-free rendering at high display refresh rates.
   - Rich query and prediction interfaces: raycasting, shape sweeps, volume overlaps,
     water/wind field sampling, ballistic trajectory lookahead, and speculative
     ghost sandboxes.

## Design

### Low-Level Architecture: `GNfiz`

The `fiz` module provides pure data-driven physics primitives without any coupling
to engine worlds or scene hierarchies:
- Defines the canonical `UnitOfTime = std::chrono::nanoseconds;` for all physics/simulation.
- 100% strict forward determinism: bit-identical reproducible results from identical initial states and integer timestamps.
- $T$-symmetry where physically permissible: solvers support negative integer durations ($-\Delta t$) for conservative laws via symplectic integrators.
- Operates in unit-agnostic 32-bit floating-point precision (`Scalar`), independent of E2's 128-bit coordinate space (user defines whether 1.0 is meters, AU, or micrometers).
- Exposes pure virtual interfaces in `src/inc/garnet/fiz/*.h` guarded by `__GN_INSIDE_FIZ_H__`.
- Encapsulates Jolt Physics C++ bindings, avoiding leaking external headers into client code.
- GPU simulations emit `gpu2` compute resources that convert directly into `rdg2` artifacts
  for rendering with zero CPU readback.
- Shared GPU Geometry & Procedural Streaming: GPU simulations (`Gel`, `Weft`, `Strand`, `Tide`)
  share vertex buffers directly with rendering (zero CPU readback, zero GPU duplication);
  procedural generators stream out once to shared GPU buffers to guarantee bit-identical
  physical-visual alignment and 50% compute savings.

### High-Level Architecture: `e2::PhysicalDomain`, `PhysicalTableau` & `PhysicalFacet`

- **Singleton Operating Engine**: `PhysicalDomain` is a singleton service owned by `Universe`,
  holding zero simulation data (no bodies, colliders, or islands).
- **Data Ownership**: `World` owns the connected simulation graph (`PhysicalTableau`), while
  `Form` and `PhysicalFacet` own local physical attributes.
- **Dual-Snapshot Symmetry & World Serialization**:
  - Ingress Physical Write: World requests `PhysicalSnapshot` at its logic cadence (30/60 Hz)
  - Egress Visual Read: World captures `VisualTableau` for `VisualDomain` (READ).
  - Ingress writes and egress reads are serialized within each world step, preventing torn states.
- **128-bit Coordinate Rebasing**: Anchors simulation zones to 128-bit $O_{sim}$ and scales into
  32-bit float meters for `fiz`, eliminating floating-point jitter across planetary-scale worlds.
- **Query & Prediction**: Thread-safe spatial queries (raycast, sweep, overlap), environmental
  field sampling, and speculative ghost sandboxes.

--- WORKFLOW / CONVENTIONS ---

- Keep changes small, modular, and verifiable at every step.
- All code must build cleanly with zero warnings (`/WX` on MSVC, `-Werror` on GCC/Clang).
- Monolithic header convention: public access strictly via `GNfiz.h` and `GNengine2.h`.
- Subheaders reject direct inclusion with guard macros (`__GN_INSIDE_FIZ_H__`).
- Pure virtual public interfaces; private concrete implementations live in `src/core/fiz/`
  and `src/core/e2/`.
- Use `AutoRef<T>` / `Ref<T>` for ownership; use `RCRT64` and `RuntimeType` for RTTI.
- Sample assets must be 100% CC0 (Public Domain), directly checked in with provenance/credits.
- Run `format-all-sources.py -d` before each commit.
