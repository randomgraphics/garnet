# Assignment: GPU2 and FX2 Bindless Raster and Transient Data Architecture

---

## Goals

Transform GPU2 and FX2 into a high-performance, bindless rendering pipeline capable
of rendering thousands of unique materials at >400 FPS by eliminating per-draw descriptor
thrashing, per-draw heap allocations, and per-draw GPU buffer creations.

1. General Transient Data Manager: Introduce a pooled transient buffer allocator
   suballocating from recyclable backing buffers (based on the retired `TransientArena`),
   integrated into `GpuRaster`, `GpuCnC`, and `GpuPayload`.
2. Vulkan Buffer Device Address & Descriptor Indexing: Enable Vulkan 1.2 core features
   for 64-bit GPU virtual addresses (`bufferDeviceAddress`) and unbounded descriptor arrays.
3. Pass-Wide Bindless Descriptor Set in `GpuRaster`: Bind pass-wide texture arrays once
   per render pass, eliminating per-draw descriptor set binding.
4. Modernized FX2 Shader ABI: Update lit kernels and shaders to consume material parameters
   via 64-bit Buffer Device Addresses and bindless texture indices in push constants.

---

## Design

### 1. General Transient Data Manager (`TransientArena` / `TransientBuffer`)
- Re-architect transient buffer allocation based on the proven `TransientArenaVulkan` design.
- Backing buffers (`VkBuffer` + host-visible/device-addressable memory) are preallocated
  and recycled across frames once live suballocations drop to zero.
- `TransientBuffer` represents an aligned slice `[offset, offset + size)` of a backing buffer:
  - Supports CPU mapping (`map()` / `unmap()`, `setContent()`).
  - Supports 64-bit GPU virtual address querying (`gpuAddress()`).
  - Carries Vulkan handles (`nativeBuffer()`, `offset()`, `size()`).
- The transient manager is owned by / attached to `GpuRaster` and `GpuCnC` recorders, and
  its allocated backing buffers are retained by `GpuPayload` until execution completes.
- In `GpuCnC`: `recordUploadBuffer` uses transient staging slices instead of allocating
  new `Buffer` objects.

### 2. Vulkan Core Feature Activation
- Enable `bufferDeviceAddress = VK_TRUE` and descriptor indexing features
  (`descriptorIndexing`, `runtimeDescriptorArray`, `shaderSampledImageArrayNonUniformIndexing`,
  `descriptorBindingPartiallyBound`) in `vk::PhysicalDeviceVulkan12Features` during device
  creation in `vk-gpu-context.cpp`.
- Backing buffers enable `VK_BUFFER_USAGE_SHADER_DEVICE_ADDRESS_BIT`.

### 3. Pass-Wide Bindless Descriptor Set in `GpuRaster`
- During `collectPassResources()`, `GpuRasterPayloadVulkan` aggregates all textures into a
  pass-wide bindless descriptor array (e.g. Set 1, binding 0: `sampler2D u_textures[]`).
- The bindless descriptor set is bound once at the start of the pass.
- Individual draw calls do not assemble or bind unique `GpuResourceTable` descriptor sets.

### 4. FX2 Shader ABI with Buffer Device Address
- Shaders use `#extension GL_EXT_buffer_reference : require` to declare typed material
  references (e.g. `layout(buffer_reference, std430) readonly buffer MaterialRef`).
- Push constants (within the 128-byte guarantee) carry:
  - `mat4 worldTransform` (64 bytes)
  - `mat3x4 normalTransform` (48 bytes)
  - `uint64_t materialAddress` (8 bytes)
  - `uint32_t flags` / padding (8 bytes)
- In `lit-kernels.cpp`:
  - Material parameters and texture IDs are written into a transient buffer suballocation.
  - The suballocation's 64-bit GPU address is passed directly into the push constant block.
  - Per-draw `Buffer::create("lit-kernel.parameters", ...)` is completely eliminated.
