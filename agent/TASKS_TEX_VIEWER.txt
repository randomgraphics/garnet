TITLE: Python DDS/EXR Texture Viewer (tex-viewer)
GOAL: A standalone Python/Qt5 image viewer for DDS and EXR files that supports:
  - Full mipmap chain navigation
  - Cubemap face, array layer, and 3D depth-slice exploration
  - Zoom, pan, fit-to-window
  - Exact float pixel values under mouse cursor
  - HDR display with configurable tonemapping (Linear, Reinhard, ACES, Filmic)
  - BCn compressed DDS (BC1/3/4/5/6H/7) via texture2ddecoder
  "Done" = all the above work on sky.dds (cubemap RGBA16F) and a 4K EXR panorama.
