# Assignment: GPU2 Bindless Rendering Subsystem

---

## Goals

Implement a high-performance bindless rendering foundation in `GN::gpu2::bindless` capable of
rendering tens of thousands of unique draws at maximum GPU throughput by eliminating per-draw
descriptor set compilation, per-draw table scanning, and per-draw heap allocations.

1. **Persistent Global Descriptor Heap (`bindless::DescriptorHeap`)**:
   Introduce a long-lived, thread-safe descriptor heap with Vulkan 1.2 `UPDATE_AFTER_BIND` and
   `PARTIALLY_BOUND`, managing stable integer indices with recycling and in-place `update()` for
   background streaming.
2. **Bindless Raster Recorder (`bindless::Raster`)**:
   Implement direct Vulkan command recording with lean `DrawParameters` (no `GpuResourceTable`),
   plain POD `CreateParameters` with conflict validation against `heapSetIndex`, internal
   `VkPipelineLayout` caching in `gpu2`, and `retainResource()` for parameter buffer lifetime
   management.
3. **Bindless Payload & Automated Invariants (`bindless::Payload`)**:
   Implement automated attachment transitions on `beginRendering` and `endRendering`, restoring
   resources to `SHADER_READ_ONLY_OPTIMAL` with write-cache flushes. Output an opaque `GpuPayload`.
4. **Verification & Demonstration**:
   Validate with comprehensive unit and stress tests in `GNtest-internal`, and build a runnable
   sample application in `src/sample/` demonstrating the bindless renderer.

---

## Design

### 1. `bindless::DescriptorHeap`
- Public interface in `<garnet/gpu2/bindless.h>` under `namespace GN::gpu2::bindless`.
- Thread-safe slot allocator with free-list recycling.
- Allocates persistent descriptors in an unbounded array (e.g. Set 0 or Set 1: `sampler2D u_textures[]`).
- Supports sampled textures, storage images, and buffers via `GpuResourceView`.
- In-place `update(slot, view)` allows swapping placeholder textures on the fly.

### 2. `bindless::Raster` & Pipeline Layout Caching
- Accepts plain POD `CreateParameters`: `heap`, `heapSetIndex`, `passResources`, `pushConstantSize`.
- Fast validation in `create()`: checks `passResources` does not conflict with `heapSetIndex`.
- Internal hashing and caching of `VkPipelineLayout` in `gpu2`.
- Direct Vulkan recording emitting `vkCmd*` calls, completely bypassing `rv::Drawable`.
- `retainResource(AutoRef<RCRT64>)` keeps dynamic parameter buffers alive in the payload.

### 3. Automated Barriers & `GpuPayload`
- The pass begins with attachments transitioned to optimal write layouts.
- At pass end, attachments transition automatically to `SHADER_READ_ONLY_OPTIMAL` with cache flush.
- Sealed `GpuPayload` plugs directly into `GpuContext::submit()`.
