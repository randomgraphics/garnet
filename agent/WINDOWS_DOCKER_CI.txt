# Assignment: Windows Docker build environment and CircleCI migration

---
## Goals
Build and verify a Windows dependency image, publish it as
randomgraphics/garnet-windows:<revision>, then move Windows CI to CircleCI.

---
## Design
Use Windows Server Core 2022 with VS 2022 C++ Build Tools, Windows SDK,
Git/LFS, CMake, Python and the repository's Vulkan SDK version. CircleCI
must use a Windows machine executor to run this Windows container.
Keep image scripts in env/docker/windows. Publish only after all three
build variants pass. Preserve existing CI until verification/publication.
